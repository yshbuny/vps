## 用券之前，这几个坑值得看一眼

**券过期问题。** 30 天有效期意味着领到券之后别囤着，尤其是决定长期购买前，先把机器试用一次、确认线路合适，再决定用哪张券买长期。

**券的类型要对上计费周期。** 年付专用券拿去月付下单不会生效，反过来也未必划算。下单前确认券面写的是"新购""续费"还是"年付"。

**渠道券的折扣越高，稳定性越依赖对方。** 65 折券由推广渠道（也就是你注册时填写的邀请码对应的上级）发放，邀请关系一旦确定无法更改。社区里也出现过"65 折券后来领不到"的讨论，所以不要把长期预算押在一张需要别人发的券上。

**返利积分的等级会掉。** Ⅲ 级及以上会员是季度评级，本季度消费不达标会降级，返利比例也跟着降。

**退款政策。** 雨云支持 7 天无理由退款（每个账号限 3 次），云服务器和游戏云可以 1 元试用一天（部分较贵机型 20 元/次）。先试后买比任何优惠码都实在——用 1 元确认延迟和稳定性，比省那几十块钱重要得多。
